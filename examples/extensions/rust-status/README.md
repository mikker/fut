# Rust status extension

This is a complete API v1 extension written as one dependency-free Rust
executable. It handles a palette command, parses versioned workspace-hook JSON,
reads resolved extension configuration, and publishes a declared workspace
token through the public Fut CLI. No platform binary is checked in.

Build a package copy so generated bytes do not enter the source tree:

```sh
cp -R examples/extensions/rust-status /tmp/rust-status
mkdir -p /tmp/rust-status/bin
rustc --edition=2024 -O \
  -o /tmp/rust-status/bin/rust-status \
  /tmp/rust-status/src/main.rs
fut extension validate /tmp/rust-status
```

Then add `/tmp/rust-status` to `extensions` or install that built directory
with `fut extension install /tmp/rust-status`. A source-only checkout is not an
installable compiled package: Fut validates and copies package files but never
runs a compiler or build script.

Optional configuration demonstrates the JSON config boundary. `label` is
shown by the command; `log_path` records commands and hook payloads and should
point outside a managed package because managed packages are read-only.

```toml
[extension.rust-status]
label = "my extension"
log_path = "/tmp/rust-status.log"

[ui.bindings]
"rust-status:probe" = "R"

[ui.sidebar.left]
components = [
  { component = "workspaces", row = { right = [{ token = "workspace.extension.rust-status.last_event" }] } },
]
```

The token becomes `workspace.created` or `workspace.renamed` after those
events. The small JSON reader is included only to keep the example build to one
`rustc` command; production extensions should normally use their language's
mature JSON library and reject duplicate keys and unsupported payload versions.

Run Fut's checked-in conformance smoke test with:

```sh
scripts/extension-conformance
```

The smoke test builds a temporary package, calls public `fut extension
validate`, starts Fut with global and workspace config, invokes the command
through its public key binding, triggers a hook with public `fut workspace
rename`, and observes the published token with public `fut --json list`.
