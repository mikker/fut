# Jump dialog: type-to-filter quick switcher

A palette-style dialog on the shared chrome that filters all sessions/workspaces/tabs/panes by typed query and switches on enter — the type-to-filter complement to the navigator's structural keys (s/w/t/p cycle, [/] and J/K jumps, arrows for parent/sibling). We considered folding filtering into the navigator behind ctrl-modified keys, but plain-letter navigation and text input conflict; a separate Jump dialog keeps both clean.
