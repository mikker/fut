# Companion package: opinionated worktree/workflow bundle on top of fut

Fut stays naive: mechanism, not policy. A separate package builds on the plain CLI and the event stream to ship opinions — auto-opening git worktrees as workspaces (via git hooks or discovery), project conventions, default tab setups, and whatever else fits the everything-works-together bundle. Fut never learns what a worktree is; the companion owns all of it. Precedent: git plumbing/porcelain, tmux vs tmuxinator.
